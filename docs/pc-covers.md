# Обложки с Windows

Генератор работает на ПК. Он читает видео через SMB и создаёт JPEG рядом с ним:
`Название.mkv` → `Название.jpg`. Медиафайлы открываются только на чтение.
Существующие JPEG не перезаписываются. Параллельного кодирования нет.

Требуются Python 3.10+, Pillow и FFmpeg с ffprobe. Установите Python и FFmpeg
из доверенного источника, затем Pillow в выбранное окружение:

```powershell
python -m pip install -r scripts/pc/requirements.txt
```

Откройте сетевую папку в Проводнике и войдите в NAS. Генератор не принимает
и не хранит SMB-пароли. Удобнее обращаться по имени NAS, если Windows уже
запомнила подключение к нему, а не создавать второе подключение по IP.

Скопируйте `examples/covers.example.json` в `.local/pc/covers.json` и укажите
свои пути. Этот файл исключён из Git.

```powershell
# Сначала только подсчитать отсутствующие обложки:
./scripts/pc/Generate-Covers.ps1 -Plan
# После загрузки новых фильмов:
./scripts/pc/Generate-Covers.ps1
# Или без сохранённого конфига:
./scripts/pc/Generate-Covers.ps1 -Root '\\nas-hostname\video' -FFmpeg 'C:\Tools\ffmpeg\bin\ffmpeg.exe'
```

Можно ограничить запуск параметром `-Limit 5`. По умолчанию файлы моложе пяти
минут пропускаются: загрузка торрента могла ещё не закончиться. Размер и время
изменения дополнительно сверяются после извлечения кадра. Для завершённых
загрузок задержку можно изменить через `-MinimumAgeSeconds`.

Размер кадра — до 1280 пикселей по ширине. Для HDR применяется тональная
компрессия в SDR; проверяются несколько кадров, чтобы не публиковать чёрную
заставку. Это требует полной сборки FFmpeg с фильтрами zscale и tonemap.

Отчёты находятся в `.local/cover-jobs/`. При ошибках код завершения ненулевой;
следующий запуск снова обработает только файлы без обложки. Для DLNA включите
в Synology Media Server отображение обложек видео из соседних изображений.
Сервер NAS Media Folders использует подготовленные JPEG без повторного сжатия.

## Метаданные новых видео

При необходимости добавьте `-MetadataFile '\\nas-hostname\shared-config\video-metadata.jsonl'`
или поле `MetadataFile` в локальный JSON-конфиг. Путь к этому же файлу на NAS
укажите в настройках сервера. Генератор объединяет метаданные новых обработанных
видео с существующими записями, сохраняя остальные. Обновление файла атомарное;
одновременно запускайте только одну задачу. Сервер подхватит изменения при
очередном обновлении индекса. Готовые обложки по-прежнему пропускаются; этот режим
не делает повторный обход метаданных уже обработанной библиотеки.
